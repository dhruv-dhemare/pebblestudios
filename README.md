# Pebble Studios

Studio site for Pebble Studios (Pune). React (JSX), Vite, plain CSS.

## Run

```bash
npm install
npm run dev
```

## Before you go live

Edit `src/data/site.js`:

- real email
- real phone (`phoneDisplay` and `phoneTel`)
- WhatsApp number as digits only, with country code (`whatsapp`)
